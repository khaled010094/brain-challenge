العربية

لعبة Brain Challenge هي لعبة ألغاز تعمل داخل المتصفح. في الإصدار الحالي:

  • لا نطلب إنشاء حساب أو إدخال اسم أو رقم هاتف أو بيانات شخصية.
  • يتم حفظ أفضل نتيجة محليًا على جهازك باستخدام مساحة التخزين المحلية للمتصفح (Local Storage).
  • لا تحتوي النسخة الحالية على إعلانات أو أدوات تحليل أو تتبع، ولا ترسل نتيجة اللعب إلى خادم خاص باللعبة.
  • يمكنك مسح بيانات اللعبة من إعدادات المتصفح لمسح النتيجة المحفوظة.

يتم استضافة ملفات الموقع عبر GitHub Pages؛ وقد يعالج مزود الاستضافة بيانات تقنية أساسية عند زيارة الموقع وفق سياساته الخاصة.

إذا أضفنا إعلانات أو خدمات خارجية مستقبلًا، فسنحدّث هذه السياسة قبل تفعيلها.

للاستفسارات أو الإبلاغ عن مشكلة، يمكنك فتح بلاغ في صفحة مشكلات المشروع على GitHub.

English

Brain Challenge is a puzzle game that runs in your browser. In the current version:

  • No account is required, and the game does not ask for your name, phone number, or personal details.
  • Your best score is stored locally on your device using browser Local Storage.
  • The current version contains no ads, analytics, or tracking tools, and it does not send gameplay scores to a game server.
  • You can clear the saved score by clearing this site's browser data.

The site is hosted using GitHub Pages. The hosting provider may process basic technical access data under its own policies.

If advertising or other third-party services are added later, this policy will be updated before they are enabled.

For questions or bug reports, use the project issue tracker on GitHub.
